# GDG AI/ML Executive Tasks

Python solutions for GDG Recruitment tasks covering Pandas preprocessing, Linear Regression, and Decision Tree Classification.

## Tasks Included
1. **`task1_pandas.py`**: Handles missing data imputation and average calculations using Pandas.
2. **`task2_regression.py`**: Trains a Linear Regression model with Scikit-learn and plots predictions using Matplotlib.
3. **`task3_classification.py`**: Implements a Decision Tree classifier on the Iris dataset.

## How to Run
```bash
pip install pandas scikit-learn matplotlib
python task1_pandas.py
python task2_regression.py
python task3_classification.py
